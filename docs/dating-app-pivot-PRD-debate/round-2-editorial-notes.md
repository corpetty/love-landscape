## Rejected

1. **AD#8's remedy (rename to "assessment growth experiment," drop the dating frame).** The diagnosis was accepted (see Addressed #7) but the remedy rejected: stripping the dating question from the document would un-instrument it — F0.8 and the intent gate only exist because the pivot is the live question, and a growth PRD with a hidden dating agenda would be *more* manipulative, not less. The fix chosen is explicitness: the pivot is named, not presumed, and branch B kills it.
2. **AD#9 ("every section returns no, therefore the go is motivated").** Partially rejected. The sections return "insufficient evidence for a dating app," and the requested decision was shrunk (across two review rounds) to match exactly that: Step 0 plus a mostly-no-regret instrumented experiment. A framework in which acknowledged weaknesses invalidate any forward step would make all cheap experimentation impossible; the document's job is to make the weaknesses priced, visible, and falsifiable, which §9 now does. The valid kernel — that candor must not substitute for consequence — was adopted via the branch/consequence structure.
3. **AD#5's implicit demand for a costly intent signal (deposits, etc.).** Rejected as premature and funnel-hostile at this scale; adopted instead: cost gradient (account + city), pre-results status capture, validity conditions, and honest downgrade of what the signal proves.
4. **RA#5's implication that the 35/27/24 drivers be removed.** Retained with an explicit unverified-secondary flag and de-weighted phrasing (single mention, non-load-bearing); removal would discard directionally consistent context the reader can weigh with the flag attached.
